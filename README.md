# 🚶‍♀️ SafeWalk – Night Safety Web App

SafeWalk is a web-based safety application designed to help users stay safe during night travel. It provides real-time location detection, nearby police station search, emergency tools, and quick safety tips.

---
## 🚀 Live Demo
👉 https://safewalk.netlify.app/
---


## 🚀 Features

* 📍 **Detect Current Location**

  * Uses browser geolocation to find user’s position

* 🚓 **Find Nearest Police Station**

  * Live search using OpenStreetMap API
  * Get directions directly via Google Maps

* 🚨 **Emergency Alarm**

  * Plays a loud alarm sound to attract attention

* 🔦 **Flashlight Mode**

  * Turns screen into bright light for visibility

* 📩 **Quick SMS to Police**

  * Sends emergency message with location link

* ⚠️ **Safety Tips**

  * Provides guidance for dangerous situations

* ☎️ **Emergency Contacts**

  * Police, Women Helpline, Ambulance numbers included

* HTML5

## ▶️ How to Run

1. Download or clone this repository
2. Make sure all files are in the same folder
3. Open `index.html` in your browser
4. Allow location access for full functionality

---

## ⚠️ Note

* Location access is required for finding nearby police stations
* Alarm sound file (`alarm.mp3`) must be present in the project folder
* Internet connection is needed for API calls
